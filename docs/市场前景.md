# 声学相机 · 市场前景分析

> 本文所有价格与技术参数均标注来源或推导依据。无法核实的数据一律不引用具体数字。

---

## 一、产品定义

一句话：**8 元均匀圆阵 + 树莓派驱动的低成本声源可视化设备。**

- 硬件：8 颗 PDM MEMS 麦克风，均匀圆阵，半径 44.19 mm；PCMD3180 做 PDM→TDM 转换；树莓派 4B 采集与计算
- 软件：SRP-PHAT 波束形成，实时输出方位角热力图，浏览器端展示
- 成本：整机物料约 **1000–1500 元**（含树莓派）

它解决的是同一个问题：**「声音在哪」**——把不可见的声场变成可视的颜色分布。

---

## 二、市场分层

声学相机不是新品类，但价格带断层极其严重。

### 2.1 高端：工业检测仪器

| 代表产品 | 麦克风数 | 典型用途 |
|---|---|---|
| Fluke ii900 / ii910 | 64 | 压缩空气泄漏、局部放电 |
| FLIR Si124 | 124 | 电力设备局放、气体泄漏 |
| SM Instruments BATCAM | 30–120 | 汽车 NVH、家电异响 |

**价格锚点（实测）**：Fluke ii900 在国内工业品电商的挂牌价为 **¥248,306.34 / 台**
（来源：MyMRO 我的万物集商品页，2026-10 抓取）

这个价位决定了客户画像：电力、石化、轨道交通、大型制造企业的**设备科 / 运维部门**。
买它不是买设备，是买一份"巡检合规能力"——所以对价格不敏感，对资质、防爆、防水、售后极度敏感。

**结论：这个市场我们进不去，也不该进。**

### 2.2 中端：教育科研与创客

- 高校声学、电子信息、自动化、车辆工程的实验室
- 电子设计竞赛、毕业设计、创新项目
- 需求特征：**要能讲清原理、能改代码、价格在几千元以内**

目前这个层级的现状是：要么用 MATLAB / COMSOL 做纯仿真（看得见公式，看不见真实声场），
要么拿开源麦克风阵列板自己拼（硬件有了，算法和上位机要自己写）。

**这是我们真正能落地的市场。**

### 2.3 嵌入式：声源定向模块

机器人、AGV、智能家居、安防等场景要的往往**不是一个"图像"，而是一个方位角数字**：

- 服务机器人：转头朝向说话人
- 摄像头：自动转向声源
- 安防：枪声 / 玻璃破碎的方向判定

这类客户不需要 40 dB 的动态范围，只需要"哪个方向有声音"，对成本极其敏感。

## 三、能力边界（必须先说清楚）

拿 8 个麦克风去对标 64 个麦克风的仪器，是自欺欺人。先把差距量化：

| 指标 | 本产品（8 麦，R=44.19 mm） | 工业级（64–128 麦） |
|---|---|---|
| 方位分辨率（4 kHz） | **约 40°** | 1–5° |
| 有效带宽 | **≤ 5 kHz**（相邻阵元 33.8 mm，空间混叠上限 5071 Hz） | 20 kHz |
| 正前方盲区 | **±10°**（环形阵固有，θ→0 时各阵元等距，相位差消失） | 二维填充阵列，可做到很小 |
| 成像形态 | 单个方位角 + 粗略仰角 | 连续二维图像 |
| 价格 | 千元级 | 20 万元以上 |

**三条硬约束来自物理，不是工程没做好：**

1. 阵元间距 33.8 mm → 5 kHz 以上出现栅瓣，一个哨声会同时点亮多个方向
2. 圆阵在轴线方向严格旋转对称 → 正前方分不出方位
3. 8 个点的空间采样 → 分辨率下限由孔径和阵元数共同决定

所以产品定位必须避开"成像"这个词，用"**声源定向**"更准确。

## 四、可切入的三个场景

### 场景 A：教学实验平台（首选）

把"波束形成"从公式变成可以拖动滑块、看得见波形对齐的实验。

**卖点**：

- 代码全开源，学生能改算法、换阵型、看中间量
- 一套设备覆盖「阵列设计 → 采集 → 波束形成 → 可视化」完整链路
- 已有的「原理分析」交互页可直接作为课堂演示

**风险**：采购周期长、单价低、走招投标流程。

### 场景 B：竞赛与毕设套件

电子设计竞赛、挑战杯、大创项目每年有稳定的参赛基数，这类需求**决策链短、对性能要求明确、愿意为"能跑起来"付钱**。

**卖点**：开箱即用的 8 通道同步采集 + 可视化上位机，省掉学生最耗时的硬件调试。

### 场景 C：声源定向模块（长期）

只卖"板 + 固件 + 串口 / 网络接口"，输出方位角。客户是自己的整机厂。

这条路的天花板最高，但需要先把前面两个场景跑通、验证算法稳定性。

## 五、竞争格局

| 类型 | 代表 | 优势 | 我们的差异 |
|---|---|---|---|
| 工业仪器 | Fluke / FLIR / SM Instruments | 性能、资质、渠道 | 不正面竞争 |
| 开源阵列板 | ReSpeaker、Matrix Voice 等 | 生态成熟、有社区 | 我们提供完整的国产化链路：PCB + 驱动补丁 + 算法 + 上位机 |
| 国产阵列模块 | 讯飞、声智等 | 量产成本、语音算法 | 他们是"语音交互"，我们是"空间定位"，解决的不是同一个问题 |

**真正的差异化不在硬件，在"整条链路都是自己的"**：
从 Gerber、器件选型、内核驱动补丁、设备树、寄存器配置，到波束形成算法和前端界面——
这套东西的价值在于**可解释、可修改、可教学**，而不是性能指标。

## 六、市场规模估算（自下而上）

公开研究报告对"全球声学相机市场"的规模口径差异很大（有的把工业超声检测全部算进去），
**在无法核实的情况下不引用具体数字**。改用可推演的算法：

**教学市场（TAM）**

| 假设 | 取值 | 说明 |
|---|---|---|
| 国内开设相关专业的高校 | 300 所 | 声学 / 电子 / 自动化 / 车辆，保守估计 |
| 每校相关实验室 | 2 个 | 声学实验室 + 电子实验室 |
| 年更新 / 新增比例 | 5% | 教学设备通常 5–8 年一换 |
| 单价 | 3000 元 | 含树莓派与外壳 |

→ 年市场规模约 **90 万元**。

这个数字**很小**，必须承认。它支撑不了一家公司的营收，但足以支撑一个小团队的产品迭代，
并且是通往场景 C 的必经台阶。

**竞赛市场**：每年参赛队伍数以万计，若渗透 1%，按 2000 元/套计，量级在百万元级。

## 七、商业化路径

    阶段一（0–1 年）  开源 + 课程套件
                      目标：跑通 20 套，收集真实使用反馈
                           ↓
    阶段二（1–2 年）  模块化：只卖板 + 固件，砍掉树莓派
                      目标：把单价压到 500 元以内，进入创客市场
                           ↓
    阶段三（2–3 年）  垂直定制：机器人声源定向、安防异常声检测
                      目标：从"卖硬件"转向"卖方案"

## 八、风险

| 风险 | 说明 | 应对 |
|---|---|---|
| **技术天花板** | 8 麦分辨率 40°，做不出"声学照片" | 不承诺成像，只承诺定向；把限制写进文档 |
| **教育市场容量小** | 年规模不足百万 | 作为验证场，不作为终局 |
| **采购周期长** | 高校设备采购通常按年度预算 | 先做开源社区，积累口碑再转采购 |
| **开源方案竞争** | ReSpeaker 生态成熟 | 差异化在中文文档、国产供应链、完整链路 |
| **硬件迭代风险** | 树莓派 5 与 4 的内核驱动完全不同 | 抽象驱动层，预留多平台支持 |

---

## 九、结论

1. **不要把它包装成"廉价版声学相机"**——那是拿 8 个麦去碰 64 个麦的短板，一测就露馅。
2. **正确的定位是"声源定向教学与开发平台"**：卖的是可理解、可修改、可复现的完整链路。
3. **市场不大，但门槛低、迭代快**，适合作为技术验证的起点，而不是终点。
4. **真正的长期价值在场景 C**——当算法在真实硬件上跑稳之后，"方位角输出"这个能力可以嫁接到机器人、安防、智能家居等更大的市场。
